# LeafyGreen activation keys
#
# PUT THIS FILE HERE BEFORE YOU INSTALL:
#     C:\Users\<Child>\leafygreen\activation_keys.txt
# (replace <Child> with the child's Windows account name). Setup reads the
# keys from the child's own folder, not from next to setup.py.
#
# List the activation keys LeafyGreen will accept, one per line:
#     KEY, YYYY-MM-DD
# The date is when that key expires. Use the word  never  for a key with no
# end date. Lines starting with # are ignored.
#
# After setup you can add, edit or remove keys any time with Ctrl+Shift+A on
# the My Account tab; the app keeps this same file up to date.
#
# ---- Replace the examples below with your own keys ----
